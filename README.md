# Family Khata Android

A phone-first Android app for family income, expense, and baki/pawna tracking.

## MVP implemented
- Income and expense entry
- Running dashboard totals
- Transaction history with delete
- Baki people list
- Four baki actions: gave, received back, took, paid back
- Automatic per-person payable/receivable balance
- Offline Room database
- GitHub Actions APK build workflow

## Build
The included GitHub Actions workflow builds a debug APK on every push to `main`.
